# Data sources: what's synthetic here, and what exists elsewhere

## Synthetic notes in this repo

All generated by this repo. No real patients, no real PHI.

| File | What's in it | Rebuild with |
|------|--------------|--------------|
| `data/datasets/train.csv` | 2,426 de-identified notes from synthetic patients; 63% in the published real-note style ([note_realism.md](note_realism.md)). Labels: chart truth (`label`), the clinician's written diagnosis (`stated_status`), grade, extent | `scripts/10_build_study.py` |
| `data/datasets/review_tasks.json` | ~240 charts with every source (note, exam form, procedure codes and diagnoses completed/planned, probing chart, radiograph AI), ready for Label Studio | `scripts/10_build_study.py` |
| `data/datasets/answer_key/review_key.csv` | The same 237 charts with generator truth and each method's reading. Reviewers must not open it | `scripts/10_build_study.py` |
| `data/corpus/corpus_sample.parquet` | 3,801 notes for the cost benchmark (not committed) | `scripts/14_benchmark_cost.py` |
| `data/samples/labeled_notes_sample.csv` | 12 short templated notes from the first benchmark | `scripts/01_build_dataset.py` |

**Realism:** diagnosis lines follow forms published for real UTHealth notes; see [note_realism.md](note_realism.md).

**Limitation:** the same author wrote the note generator and the rules that read
the notes, so the rules know the generator's phrasing. That's why rule-based
scores are high on these notes. An independently written synthetic set is a
fairer test, and real notes are the real one.

## Public synthetic dental notes

| Dataset | What it has | Access | Fit |
|---------|-------------|--------|-----|
| **Synthetic Dental Clinical Notes Dataset for Dental NLP Benchmarking** ([IEEE DataPort](https://ieee-dataport.org/documents/synthetic-dental-clinical-notes-dataset-dental-nlp-benchmarking), DOI 10.21227/tt32-vp70; T. Tamizh Selvam, July 2026) | 20,000 synthetic visit notes (JSONL/TXT). ICD-10 diagnosis labels, tooth-level annotations, internal procedure labels (not CDT), visit type, summaries, splits. Benchmark tasks include periodontal metric extraction and tooth-level NER | IEEE DataPort subscription. No license listed on the page. Generation method not described on the page | **Best candidate for a second, independent test set.** Check the license and review a sample before using it in a publication |
| **UTHealth / UCSF synthetic notes** (Chuang, Lee, Tokede, Lin, Brandon, Tran, Jiang, Walji; [arXiv 2407.21050](https://arxiv.org/abs/2407.21050v3)) | 450 notes generated with GPT-4 from 15 de-identified templates, labeled status / stage / grade / extent / subtype; RoBERTa trained on them, tested on 240 dentist-labeled real notes per site | Release not stated in the paper | Same label schema as this repo. Ask the authors |
| **Cross-institutional dental EHR entity extraction via generative AI synthetic notes** ([NSF PAR](https://par.nsf.gov/biblio/10639435-cross-institutional-dental-electronic-health-record-entity-extraction-via-generative-artificial-intelligence-synthetic-notes)) | Follow-on from the same group | Not checked (page blocked automated access) | Ask the authors along with the one above |

## Public real-text test sets (never committed)

| Dataset | What it has | Access | Used for |
|---------|-------------|--------|----------|
| **MACCROBAT** (Caufield 2019, [figshare](https://doi.org/10.6084/m9.figshare.9764942.v2), MACCROBAT2020.zip; BIO mirror [`ktgiahieu/maccrobat2018_2020`](https://huggingface.co/datasets/ktgiahieu/maccrobat2018_2020)) | 200 clinical case reports from PubMed Central, edited to the case details, with hand-annotated entities (41 types: symptoms, diseases, procedures, drugs, lab values, dates, ages ...). The mirror holds the 2018 and 2020 releases of the same 200 | CC BY 4.0; downloaded to `data/raw/` by `scripts/32_maccrobat_deid.py --download` | De-identification test pass on real prose (original brat release by default): date recall and clinical over-redaction ([deidentification.md](deidentification.md#results-on-maccrobat-200-real-case-reports-external-spec-009), spec 009). Not dental, not chart notes |

## Not usable for notes

| Source | Why not |
|--------|---------|
| Synthea | Generates dental encounters and procedures, but no free-text notes |
| GlobalDentBench-OA | Exam-style questions and answers, not chart notes |
| BigMouth Dental Data Repository | Real EHR data under a data-use agreement, not synthetic or public |
