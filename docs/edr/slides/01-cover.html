Executive pitch · the dental record (EDR) · October 2026

The diagnosis is in the dental record.

Nobody can count it.

Can software read the chart the way a gum specialist does, at the scale of millions of visits, and prove it is right? This study builds and tests that, end to end, on synthetic records.

Health Transformation Lab

Working name · synthetic data only

John Bowyer · personal project, not affiliated with any organization

Gum disease is one of the most common chronic diseases in adults, and it is written down at almost every dental visit. But it is written down in pieces: a checkbox here, a billing code there, measurements, and a free-text note. Nobody can count it across clinics, so nobody can study it at scale, link it to diabetes, or see whether care is working. This study asks one question: can software read the dental record the way a gum specialist does, and can we prove it is right? Everything shown is on synthetic records, built so the right answer is known; it is a rehearsal of the real study, not a result on real patients. This is a personal project, not any organization's plan.
