# pull_requests/

Reviews from `/create-pr` and `/pr-review` land here as `pr-<n>-review.md` (or
`<branch-slug>-review.md` before a PR exists), overwritten on re-review. The rubric is
`.claude/review-rubric.md`: Superpowers code-review skills, verified findings only, and a
mandatory secrets, PHI and organization-claims scan. Reviews are committed, so each PR's review
stays with the history.
